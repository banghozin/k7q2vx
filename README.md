> 미국 상장 종목을 산업 밸류체인의 **층(層)**으로 세워 보여주는 한국어 사이트.

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 배포용 빌드
npm start        # 빌드 결과 실행

npm run validate # 큐레이션한 종목이 아직 상장돼 있는지 전수 확인
npm run update   # 시세 수집 + 지표 계산 (1~2분)
```

`npm run update` 는 두 단계입니다 — `fetch`(시세를 `.cache/` 에 받음) 다음
`compute`(계산해서 `src/data/generated/` 에 씀). 계산만 다시 돌리려면
`npm run compute` 만 치면 됩니다.

계산 파일이 없어도 빌드는 됩니다. 숫자 자리에 "—" 가 뜨고 층 구조는 그대로
보입니다.

의존성은 5개뿐입니다 — `next`, `react`, `react-dom`, `zustand`, `lightweight-charts`.
Tailwind를 쓰지 않고 `src/app/globals.css` 한 파일에 디자인 시스템을 직접 씁니다.

## 테마를 추가하는 법

코드를 건드릴 필요가 없습니다. 파일 하나만 만들면 됩니다.

1. `src/data/themes/` 에 파일을 만들고 `Theme` 모양대로 채웁니다.
   (`src/data/types.ts` 에 각 항목이 무슨 뜻인지 주석으로 적혀 있습니다.)
2. `src/data/themes/index.ts` 의 `THEMES` 배열에 넣습니다.

끝입니다. 네비게이션, 자동 태깅, 검색, 뉴스 매칭, 정적 페이지 생성이 전부 따라옵니다.

층은 **1층이 가장 아래(원재료·설계)**, 숫자가 클수록 최종 서비스에 가깝습니다.
데이터에는 1층부터 오름차순으로 적고, 화면에서 뒤집혀 위가 최상층이 됩니다.

## 구조

```
src/
├─ data/
│  ├─ types.ts              ← 테마·층·종목의 모양 정의
│  └─ themes/
│     ├─ ai.ts … crypto.ts  ← 테마 11개. 사람이 손으로 채우는 곳
│     └─ index.ts           ← 역방향 색인(자동 태깅)·검색·조회
├─ app/
│  ├─ globals.css           ← 디자인 시스템 전부
│  ├─ page.tsx              ← 홈: 테마 목록 + 여러 테마에 걸친 종목
│  ├─ theme/[slug]/         ← 층 지도 (정적 생성, 6시간마다 재생성)
│  ├─ notes/                ← 매매노트
│  ├─ watchlist/            ← 워치리스트
│  ├─ about/                ← 읽는 법 · 지켜야 할 선
│  └─ api/chart/            ← 야후 일봉 중계 (브라우저 직접 호출은 차단되므로)
├─ components/
│  ├─ strata.tsx            ← 지층 렌더링
│  ├─ specimen.tsx          ← 종목 카드 + 자동 태그
│  ├─ chart-modal.tsx       ← 차트 + ?stock= 딥링크
│  ├─ share-layer-link.tsx  ← 층 바로가기 + 화면 링크 복사
│  └─ notes/                ← 매매노트 폼과 목록
└─ lib/
   ├─ sbhnews.ts            ← 공개 RSS 읽기 + 라이선스 표기
   └─ store/                ← zustand + localStorage (기기 저장)
```

### 지표 계산 요약

| 지표 | 계산 |
|---|---|
| 층 온도 | 소속 종목 등락률의 **중앙값**. 한 종목이 튀어도 층이 왜곡되지 않게 |
| 동조율 | 기준 종목이 +3% 이상 오른 날(최근 1년)에 각 종목이 올랐는지. 사건 10회 미만이면 기준을 +2%, +1.5% 로 낮추고 **실제 쓴 기준을 화면에 표시** |
| 대장주 | 주도력 45% · 선행성 25% · 상대강도 15% · 자금유입 15%. **S&P500 영향을 걷어낸 뒤** 계산하고, 테마가 곁다리인 종목은 후보에서 제외 |
| 손바뀜 | 60거래일 전과 비교해 예전 1위가 3위 밖으로 밀렸을 때만 |

이 지표들의 설계 근거와 세 번의 실패 과정은 `PROGRESS.md` 에 있습니다.
**건드리기 전에 읽어 주세요** — 상식적으로 보이는 단순한 방법들은 대부분
이미 시도했고 무너졌습니다.

### SBHNews 이용 조건 준수

[data-use 페이지](https://www.sbhnews.com/data-use)가 **CC BY 4.0**으로
사전 승인 없는 수집·재배포·상업 이용을 허용합니다. 지키고 있는 것:

- `robots.txt` 가 막은 `/api/` 는 건드리지 않고 **공개 RSS만** 사용
- 하루 1회 수준의 캐시로 같은 문서를 반복 요청하지 않음
- 429·오류 시 즉시 포기
- 모든 기사에 출처명 · 제목 · 원문 URL · 라이선스 링크 · 가공 여부 표시
- **시세 숫자는 가져오지 않음** — 제3자 권리 자료라 CC BY 4.0 대상 밖

## 지켜야 할 선

- 매수·매도 의견, 목표가, "추천" 표현을 넣지 않습니다.
- 매매노트의 모든 숫자는 **사용자가 직접 적은 값의 산수**입니다.
  적정 매수가·목표가를 계산해 제시하지 않습니다.
- 앞으로 붙일 동조율은 **과거 기록이지 예측이 아니라는 문구**를 숫자 옆에 둡니다.
- 표시되는 종목은 산업 구조 설명을 위한 분류 예시입니다.
